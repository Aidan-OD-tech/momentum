# Product

## Goal

Help a student turn a dense assignment brief into manageable steps, start working, and return after a pause without rebuilding their context. Audience includes students who feel overwhelmed or put things off. Full rationale: [MOMENTUM_CONTEXT.md](MOMENTUM_CONTEXT.md).

## MVP

In: one active assignment; pasted-text brief and optional deadline; summary, requirements, editable steps with approximate estimates and "Done when"; full plan and original brief access; optional timer (off by default); per-step return notes and pause/resume; step completion and undo; final requirements check; completed home; honest loading, error, empty and success states.

Out: PDF import, accounts, cloud sync, multiple-assignment management, calendars, streaks, adaptive scheduling, document editing or verification, submission integrations. Momentum never submits or verifies anything.

Storage is browser-local only. Plan generation (M4) is a server-side model call; the API key never reaches the browser.
